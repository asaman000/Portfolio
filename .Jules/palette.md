## 2025-01-08 - Adding Keyboard and Screen Reader Accessibility to Div-Based Buttons
**Learning:** Found an accessibility issue pattern specific to this app's components where video thumbnails (acting as buttons to open a lightbox) were implemented using generic `div` elements with only an `onclick` handler. This made them completely inaccessible to keyboard and screen reader users, preventing them from interacting with the core content.
**Action:** When creating or modifying `div`s that act as interactive elements (like buttons) in this app, ensure they include `role="button"`, `tabindex="0"`, `onkeydown` handlers for 'Enter' and 'Space' keys, and appropriate `aria-label` attributes to make them fully accessible and properly interpreted by assistive technologies. Also add `aria-label` to icon-only buttons like the close `&times;` symbol in lightboxes.
