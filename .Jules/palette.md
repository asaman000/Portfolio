## 2024-08-20 - [Add Keyboard Focus Indicator]
**Learning:** The custom glassmorphism design system in this app relied solely on hover states and neglected keyboard focus indicators across elements. This is a common pattern in highly visual UI systems where designers may optimize for mouse users over keyboard navigability.
**Action:** When working on similar visually-heavy UI systems or glassmorphism patterns, always check for keyboard focus indications and proactively implement `:focus-visible` styles early in the design implementation.
